#difficulty {
    padding: 10px 40px 10px 14px;　←余白
    font-size: 16px;　←フォントサイズ
    border: none;　←枠線を追加(本体の一部を枠線にする)
    border-radius: 4px;　←枠線の角を丸める(本体の角を丸めるのにも使う)
　　※outlineなら、本体の外側に輪郭を追加できる。フォーカス状態の強調に使える。
    background-color: #eee;　←背景色
    cursor: pointer;　←カーソル
    appearance: none;　←ブラウザやOSのデフォルトの見た目を非表示
    box-shadow: 0 2px 5px rgba(0, 0, 0, 0.2);
}

HTML、JavaScript

div…division（区分け・分割）。ウェブページの中で意味を持たない汎用的な箱（コンテナ）のこと。複数の要素をまとめてグループ化し、CSSでデザインやレイアウトを適用するために使う。

const…constant（定数・不易なもの）。一度決めた値をあとから変更（再代入）できないように固定する。

addEventListener…もし○○が起きたら、この処理をしてください。(処理を下に書く)

行（row）と列（col）※0から数える。1つ目が0。
左上 → row 0 / col 0
右上 → row 0 / col 9
左下 → row 9 / col 0
右下 → row 9 / col 9
